# Pesquisa de pessoas — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar primeiro a pesquisa gratuita com Hermes, CNPJ e OAB, o resumo do revisor e o descarte confirmado. Preparar a passagem posterior de contatos pagos com autorização individual do Nick.

**Architecture:** Módulo pessoas independente, entradas em leitura e resultados próprios por lote. O agente Hermes no Studio executa web_search. O Python recebe os resultados estruturados, abre as páginas públicas e valida os trechos. A leitura de evidências usa o mesmo gateway em modo sem ferramentas. CNPJ, OAB e provedor licenciado têm interfaces independentes.

**Tech Stack:** Python >=3.12, biblioteca padrão (urllib, ssl, csv, sqlite3, dataclasses, hashlib, ipaddress), openpyxl e certifi existentes; pytest no desenvolvimento. Sem dependências novas.

**Spec:** `docs/superpowers/specs/2026-11-23-pessoas-design.md`.

## Global Constraints

- Este plano só será executado em tarefa separada, após aprovação. Esta entrega cria somente os dois documentos.
- TDD, sem rede: transporte, resolução DNS, relógio, Hermes, busca, registros e provedor falsos; JOÃO EXEMPLO e BANCO EXEMPLO S.A.; arquivos somente em tmp_path.
- Nenhuma tarefa abre, lista, busca ou executa algo contra dados/ ou saida/ reais. Primeira rodada real é do Nick.
- DJEN e aprofundamento permanecem inalterados; usar utilitários públicos existentes em leitura.
- A primeira rodada é gratuita, com o provedor pago desabilitado. Futuramente, exigir `Confirmado = sim`, `Autorizar consulta paga = sim` para o mesmo candidato e execução de `contatos` por Nick. Antes da cessão, o contato humano abrange apenas o credor ou o advogado dele.
- Nunca pesquisar terceiros ou sócios de PJ devedora que não sejam partes; nunca contactar alguém.
- HTTP da aplicação sequencial, pausa padrão 5 s, mínimo 3 s, sem reenvio automático; página 5 MB, timeout web 25 s; modelo timeout 180 s.
- .env ignorado antes de qualquer configuração; nunca criar .env neste plano automatizado.
- Saída textual e erros sem nomes, CPF, contatos ou segredos; exceção de diagnóstico: endpoint de modelo sanitizado. Na prévia de descarte, a CLI também pode exibir os rótulos de revisão dos casos e o código de confirmação, sem identificadores pessoais.
- Testes unitários só demonstram contrato com fixtures. O ensaio impessoal anterior verificou busca e autenticação do Hermes. Os testes deste plano não atestam disponibilidade, licenças, controles do gateway nem cotas reais dos fornecedores.
- Commits convencionais por tarefa na branch autorizada feature/pessoas, somente paths explícitos; nada de git add .; sem coautoria inventada.
- A implementação manual dos adapters reais depende dos contratos e escolhas da spec §16; não tratar fake como integração pronta.

## Review Focus

1. Nick ordenou Excel ou duplicou uma linha: decisões seguem IDs, duplicatas falham antes de rede — Task 9.
2. CPF começa por zero e Excel o converteu em número: exigir célula textual e dígitos válidos, nunca completar silenciosamente — Task 10.
3. Modelo responde JSON inválido ou instrução maliciosa: erro explícito sem novas chamadas ou ações — Task 4.
4. Queda após fornecedor cobrar, antes de salvar: estado incerto bloqueia repetição até conciliação — Task 10.
5. Bearer enviado por proxy, redirecionamento ou resolução externa de localhost: recusar antes do envio e manter o cabeçalho fora das páginas públicas (Task 3).

## Mapa de arquivos

Todos os caminhos de módulo abaixo começam em `src/guicredito/pessoas/`; os testes em `tests/pessoas/`.
- `__init__.py`: pacote; `modelos.py`: registros/estados/interfaces.
- `config.py`: .env e parâmetros; `http.py`: transportes público/loopback separados. O Bearer existe só no transporte do gateway.
- `hermes.py`: descoberta do agente, Responses API, pareamento das ferramentas, leitura sem ferramentas e recorte para contexto.
- `entrada.py`: seleção, capas/Excel, alvos; `identidade.py`: CPF/CNPJ/confiança.
- `fontes.py`: slots de busca/provedor e páginas; `cnpj.py`: snapshot/SQLite; `oab.py`: cadastro/parser/manual.
- `evidencias.py`: grounding, hashes e recortes.
- `planilha.py`: decisões privadas, OAB manual e exportação do Excel. `relatorio.py`: relatório completo e projeção reduzida para `revisao.html`, definida na Task 9.
- `fluxo.py`: lote, passagens, prévia e aplicação do descarte. `__main__.py`: comandos locais.
- Fora do módulo: modificar somente `.gitignore` na Task 1 e criar `READING_PESSOAS.md` na Task 13 durante implementação.
Cada tarefa nomeia exatamente os testes que cria. Helpers sintéticos ficam em `tests/pessoas/conftest.py`.
